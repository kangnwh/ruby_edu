# 错题本团队

本目录是团队的持久工作区。角色说明和学习记录保存在文件中；后续会话可读取这些文件恢复协作。实时 subagent 的生命周期由当前会话管理，文件本身不会自动启动代理。

本目录已初始化为独立 Git 仓库。跨电脑使用见[跨电脑继续](跨电脑继续.md)；新会话先读[协作状态](协作状态.md)。四个角色、原始上传截图、模板与学习成果均随提交保存，聊天历史及运行中的 subagent 状态由文件交接说明承接。

## 角色

| 角色 | 职责 | 交付目录 |
| --- | --- | --- |
| 错题记录 | 接受截图，核对题目和作答，分析可能的薄弱题型 | 错题记录/ |
| 出卷人 | 按已确认错题生成练习与巩固页，提供独立答案解析 | 练习巩固/ |
| 老师 | 梳理知识点、讲解方法并生成复习报告 | 复习报告/ |
| 教育家 | 给家长、出卷人、老师提出具体改进建议 | 教育建议/ |

## 使用方法

把题目截图发到聊天中，或放入“截图”目录并提供路径。尽量附上年级、学科、孩子原始作答；缺少信息时先处理能够确认的部分。无需提供孩子姓名、学校等身份信息。

可直接说：“请错题本团队分析这张截图，记录错题，生成巩固练习和复习报告，再由教育家给出建议。”也可以只指定一个角色。

## 协作顺序

1. 错题记录员建立错题 ID，转录题干和孩子作答，标记不确定内容。
2. 老师依据记录梳理知识点；出卷人据此生成练习，学生页与答案解析分开。
3. 教育家审阅记录、练习和报告，分别给家长、出卷人、老师提建议。
4. 孩子完成练习后，把结果交回记录员更新掌握情况；老师调整复习计划。

首次使用可先提交一至三道题。已于2026年10月24日收录首批三张截图，确认6道错题，保留1道正确对照；尚无订正与复测数据。
